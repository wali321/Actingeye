# Acting Eye

Acting Eye is an NGO website built during a hackathon at Colvin, where I was given just **4 hours** to design and develop the project.

The goal was to create a modern, user-friendly platform focused on social impact, education, digital inclusion, and transparency. The project challenged me to turn an idea into a complete website within a limited timeframe while balancing design, functionality, and content.

## Live Demo

https://actingeye.vercel.app

## Tech Stack

- Next.js
- React
- Tailwind CSS
- JavaScript / TypeScript

## Key Highlights

- Modern, responsive design
- Mission-driven storytelling
- Education and community-focused initiatives
- Transparent impact reporting
- Built within a 4-hour hackathon timeframe

## Run Locally

```bash
git clone https://github.com/wali321/Actingeye.git
cd Actingeye
npm install
npm run dev
```

Open `http://localhost:3000` to view the project locally.
